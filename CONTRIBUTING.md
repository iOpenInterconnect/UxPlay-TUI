## Contribution guidelines
You are free to open Pull Requests and Issues at any time.
</br>
</br>
Feel free to suggest new ideas, fix what you see is broken etc. Please make sure to include a sufficient description of your changes / bug report for me to better understand.

The only **requirement** for your PRs or Issues is that you include an **AI contribution disclosure badge** as described in <https://gist.github.com/shawnphoffman/991fb9923036c6fec26997fdf2f216a8>.  
Simply copy-paste the corresponding badge and alter the description to match your scenario. See an example in [README.md](https://github.com/iOpenInterconnect#ai-contribution-disclosure)  
</br>
> [!IMPORTANT]
> Failure to fulfill the requirements above will result in an immediate closure of your PR/Issue
